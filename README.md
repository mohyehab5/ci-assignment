# Temperature Converter

[![Day 2 CI](https://github.com/mohyehab5/ci-assignment/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/YOUR_USERNAME/day2-ci-assignment/actions/workflows/ci.yml)

A small Python application for temperature conversion.

## Features

- Convert Celsius to Fahrenheit.
- Convert Fahrenheit to Celsius.
- Check whether a Celsius temperature is freezing.

## Requirements

- Python 3.12 or Python 3.13.
- pytest.

## Run Locally

Install development dependencies:

    python3 -m pip install -r requirements-dev.txt

Run the tests:

    python3 -m pytest -v
